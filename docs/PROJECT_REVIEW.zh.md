## 已完成的修复

| 问题 | 改动 |
| --- | --- |
| 打开页面就进入默认英文流程 | 增加独立的首屏语言选择。每次完整打开或刷新时先选中文或英文，选择后才挂载首页或故事页。同步更新网页标题与语言属性。 |
| 首页翻译了，正式故事页和指引仍固定中文 | 补齐播放器、资源变化提示、失败回退、新手指引、术语说明、汇率状态和错误提示的中英文文案；用可翻译文字替代英文标题图片。 |
| 中文国家、城市、学校列表仍显示英文 | 为内置院校和城市增加中文名称；国家使用本地化名称。搜索支持中文显示名，提交给搜索接口的仍是原始标识，避免破坏级联查询。 |
| 缓存书架把不同语言故事混在一起 | 后端先按语言及内容校验筛选，再限制数量；前端切换语言时重新加载。直接打开不匹配语言或混合语言的故事会被拦截。 |
| 已生成中文故事夹杂英文规划占位段落 | 修复默认慕尼黑故事的15个英文分支结果段、14个英文结局前缀和学分字段。其他旧缓存保留原文件，但不在正常书架展示不合格内容。 |
| 结局被重新加上英文规划标题 | 编译器优先采用正式结局正文，避免把内部标题拼回译好的段落。 |
| 生成校验失败仍写出“完成”文件 | 新增发布检查；未通过内容、路由或语言检查时不发布最终故事。语言漏译有最多两轮定向修复，保留数字和回退占位符，仍不合格则失败。图片生成移到校验通过之后。 |
| 旧版故事在正式播放器中不结算属性 | 正式播放器现在兼容旧版四属性，显示状态，并在属性耗尽时结束本轮。 |
| 状态与跳转处理散落，异常返回可能悄悄回到开头 | 把正式播放器的状态推进抽成可测试函数；警告页和结果页继续时不重复扣属性，失败回退保留完整决策前状态。缺失返回目标显示可恢复错误，增加重复点击保护。 |
| 较早的搜索响应可能覆盖新查询 | 国家切换、输入变化或组件退出后，忽略已经过期的城市、学校搜索响应。 |
| 同一故事可能同时启动多个后台任务 | 在异步缓存检查之后再次检查是否已有运行任务，避免重复启动。 |
| 更换实际模型或研究开关仍可能命中旧缓存 | 缓存身份现在包含实际文本模型、各服务模型与地址、实时研究开关等配置，不包含密钥。升级生成器缓存版本。 |
| 切换官方服务后仍带着中转专用文本模型 | 官方服务默认采用已有的官方模型配置；手动指定模型仍优先，避免把中转模型名直接发送到官方接口。 |
| 续生成使用不存在的 `page_id` | 改为读取实际节点ID，恢复前文摘要；将完整生成脚本纳入额外类型检查并修复相关类型错误。 |
| 学期数被编译器写死为1 | 编译输出保留研究档案中的学期数。剧情长度是否真正按学期扩展，仍属下方待决定的玩法改动。 |
| 浏览器禁止本地存储会导致启动异常 | 语言偏好和服务设置增加容错；无法持久保存时使用当前会话状态。 |
| 金额符号被误判 | 不再仅凭裸露的 `$` 或 `¥` 就断言是美元或人民币；明确的币种或金额注释仍可换算。 |
| 旧故事中的 Markdown 标记直接露出 | 正文显示时清理成对的粗体标记，保持术语标注位置正确。 |

语言处理针对玩家界面和叙事。官方名称、必要缩写、课程代码、网址和用户自行输入的名称允许保留原文；内置名称尽可能提供中文显示。开发调试页的原始数据与技术字段不是面向玩家的翻译文案。语言检查属于规则检测，不能代替人工逐句校对。

## 验证结果

- 前端 TypeScript 检查通过。
- 后端、完整生成脚本和审计脚本的 TypeScript 检查通过。
- 前端生产构建通过。
- 17项离线回归测试通过，覆盖警告与结果页返回、失败回退检查点、旧版属性耗尽、过期选择、风险阈值、无效数值、语言检查、发布拒绝、缓存配置、服务模型选择和受限存储。

## 等你决定的生成和玩法优化

下列设计改动尚未实施。

| 编号 / 优先级 | 发现 | 建议方案 | 需要决定的取舍 |
| --- | --- | --- | --- |
| 1 / 高 | 来源校验主要确认引用ID存在，不能证明每条费用、资格或失败后果都被对应页面支持。部分情节使用很绝对的后果描述。 | 为关键事实记录原文依据、适用对象、日期与核验状态；证据不足的事实使用不确定措辞，并限制其直接触发不可逆结局。 | 更严格的事实要求会减少可生成内容，也可能增加研究时间；可以先只覆盖签证、费用、毕业资格。 |
| 2 / 高 | 首页允许选择1—8学期，但完整生成器仍以固定的12个主阶段规划；其中包含毕业与就业，并未实现完整的逐学期扩展。 | 先区分“短期体验／交换”和“完整学位”两类旅程，再让节点与结束条件匹配实际时长。 | 方案A：短期只模拟一个学期；方案B：按学期生成学习、生活和关系阶段。建议先A，再逐步扩展B。 |
| 3 / 中 | 语言同时决定人物设定：中文配中国女性，英文配斯里兰卡女性，插图也绑定对应24岁角色。 | 将界面语言、国籍／签证背景、参考币种和角色外观分开设置。 | 可以保持目前预设角色，也可以增加一页简短角色设置；后者更贴近不同玩家，但增加入口步骤。 |
| 4 / 中 | 四份完整故事在随机前向选择下约有81.6%—94.4%的路线触发变量失败，平均只有5.8—8.3次决策。慕尼黑样本中，250条有117条因时间变量失败。 | 加入“练习／挑战”模式；练习模式保留充分风险提示与回退，挑战模式保持现有阈值。也可先只调整前半程的时间消耗。 | 随机策略失败率不代表真人失败率，不建议直接全局降低难度。最好先用少量玩家记录验证，再决定阈值和回退成本。 |
| 5 / 中 | 所谓最多12张图只限制剧情插图；所有警告和结局还会额外生成，且按顺序请求。 | 增加整轮总图片预算；正文先可玩，关键插图后补；只有玩家遇到的非关键场景才按需生成。 | 全图预生成更完整，但启动更慢；分批生成更快，需设计无图占位与加载状态。 |
| 6 / 中 | 生成期间只有固定过场文本；离开录取流程后，后台任务仍可能继续。当前玩家进度也只保存在组件内。 | 展示研究／规划／正文／校验／插图阶段与可重试错误；支持恢复生成任务、保存本地游玩进度，并明确“离开页面”和“取消生成”的区别。 | 先做进度与恢复即可改善等待体验；真正取消后台进程还需处理共享任务和生成中的文件。 |
| 7 / 低 | 部分选项容易被理解为“正常／积极／消极”的固定答案，且结局回顾较少展示自己做过的决定。 | 用资源与价值冲突构造选项，增加关键决定的结局回顾；沿途少量关系或记忆事件影响后续文案。 | 更强的个性化与重玩价值，需要更多内容校验；可以先做无需新增模型调用的决策回顾。 |

建议先决定1和2，避免增加内容量后进一步放大事实和时间线问题；之后做6，再根据试玩记录决定4。角色设置、图片预算和结局回顾可独立选择。
